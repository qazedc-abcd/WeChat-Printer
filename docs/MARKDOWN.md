# Markdown 排版与可选 AI

本分支使用 Dart markdown（CommonMark 基础与常用表格扩展）解析正文。文字块可自动识别 Markdown并切换原文，专用 Markdown 块始终排版。支持导入或拖入 .md / .markdown / .txt；本地提示区分写法建议与本地限制，不把所有提示都当成语法错误。

- 标题按居中单列输出；列表、引用、代码与段落转换为 content 节点。
- 表格每行单独一个 content，保持 maxcolumn、列数据和列配置数量一致；保留单元格对齐。
- 水平线转换为已实测的 divider，线长由设备决定。
- 图片需要公开 HTTP(S) 直链，发送前下载、白底缩放、黑白处理并上传当前图床。
- 原始 HTML 不会被执行，预览使用 Flutter 文本组件。
- 本地最多 16 列，5 列以上提示实测间距异常；建议优先使用 4 列以内。这不是设备最大列数。

图片可从文件导入，处理后可复制 Markdown 直链。应用输出不透明 280×280 PNG，避免设备强制方形拉伸和透明区填黑；长图不能据此得到等比例长条输出。

AI 默认关闭。在设置中配置兼容 OpenAI 的 API 基础地址、模型和 Key 后，手动点击正文块的 AI 检查。保存设置、编辑和打印不会自动调用 AI。只发送当前块正文，不附带设备 SID、图床凭据和历史记录；建议全文可预览，用户点击应用才替换原文。原文变化后，旧建议不能直接应用。

接口使用 POST {baseUrl}/chat/completions，包含 model、messages、stream:false，并解析 choices[0].message.content 内的结果 JSON。单次最多 60000 字符，超时 60 秒；AI 失败仍可使用本地检查与编辑。

小票预览用于检查内容顺序、图表和对齐，字体与间距以设备实物为准。详见 [协议与图片实测说明](PRINTAD-PROTOCOL.md)。
