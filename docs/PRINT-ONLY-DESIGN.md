# 小票台 · Android / Windows 设计与实现

本分支是 Flutter 原生跨平台应用，使用 Material Design 3，运行时不依赖 Node.js、电脑上的代理服务或 FFmpeg。保留手动打印相关功能，移除 QQ / Telegram 接入、消息队列、黑名单与管理员功能。

## 信息结构与平台适配

| 页面 | 内容 |
| --- | --- |
| 打印 | 编辑内容块、导入 / 导出文档、图片处理、预览、显式发送 |
| 记录 | 最近 50 次受理 / 失败 / 状态未知结果，用户可清除 |
| 设置 | 设备、图床、可选 AI、颜色模式，支持导入旧版配置 |

Android 使用底部 NavigationBar 与单列编辑，预览放在可滚动底部弹层。Windows 使用侧边 NavigationRail；宽度足够时显示编辑与纸面预览双栏，窄窗口自动切换为单列。提供浅色、深色、跟随系统三种模式。

界面采用低饱和绿色主色、暖白纸面、Material 语义色与原生组件。可点击目标、输入框和按钮沿用 Material 尺寸；文档工具支持键盘。设备只显示“已配置”，不伪装成实时在线检测。

## 已实现的打印功能

- 文字、Markdown、图片、短二维码、固定 divider 与空行；内容块可排序和删除。
- Markdown 自动识别与原文切换；表格、清单、引用、代码、标题和远程图片转换为打印节点。
- Windows 拖拽图片 / 文档；Android 系统文件选择；图片逐张进入调整窗口。
- 图片可选择等比例白底留白或方形裁剪，调整放大、位置、亮度和对比度，并启用 Floyd–Steinberg 抖动。
- PNG/JPEG/WebP/GIF 源图经本地解码、方向修正与白底合成，转换为不透明 280×280 PNG。解码和处理运行在 Dart isolate。
- R2/S3 原生 SigV4 上传，支持 Session Token、路径式 / 虚拟主机式寻址；兼容自定义 multipart HTTP 上传。
- 图床配置完整时，图片调整完成后自动上传；失败保留本机处理结果，允许重试。发送入口复用已上传结果，避免自动上传与打印重复上传。
- AI 默认关闭，仅显式点击时使用 OpenAI Chat Completions 兼容接口检查当前正文，建议预览后手动应用。

## 对实测结论的适配

- 原生二维码统一检查 **100 UTF-8 字节**，不静默截断；保护发生在图床上传与真实打印请求之前。这是保守策略，不是硬件安全阈值。
- 服务端 0 显示“请求已受理，是否完整出纸以设备为准”，不表示已经打印。
- 268435461 归为字段 / 枚举错误；268697729 按 msg 区分离线、正在执行其他打印任务和服务繁忙。
- 超时与连接中断标记结果未知，不自动补发 POST。
- Markdown 水平线使用已确认的 divider。没有添加尚未证明生效的图片尺寸或字号调节控件。
- 远程图片统一经过本机转换与白底填充后上传；原始长图不会被宣称能等比例直接打印。
- 16 列、20 MiB、4000 万像素、280×280 都是本地策略；5 列及以上布局给出实测提示，不宣称设备最大列数。

## 数据与边界

设备 SID、图床凭据和 AI Key 使用 flutter_secure_storage 保存。草稿和最近记录使用本机应用存储；导出的文档包含正文和处理后的图片，不包含配置对象。请求预览和复制模板隐藏设备 SN / SID。

Android 使用系统 ACTION_CREATE_DOCUMENT 保存用户导出的文件，不申请全盘存储权限。默认禁用 Android 配置自动备份，避免密钥与加密数据分离恢复。为了支持用户自选的本地 MinIO / HTTP 接口，Android 允许明文网络；推荐对公网服务使用 HTTPS。

研究详见 [协议与图片实测说明](PRINTAD-PROTOCOL.md)。本应用不会重新探测设备极限，也不会在启动、保存设置或导入文档时打印。

## 构建与验证

使用 Flutter 3.41.5 / Dart 3.11.3，Android 最低 API 24。Windows 构建需要 Visual Studio C++ 桌面工具链；CI 分别在 Ubuntu 与 Windows runner 构建 APK 和 Windows Release 包。

单元测试覆盖 SigV4 的独立 AWS SDK 签名向量、Markdown 与 divider、透明与比例处理、二维码保护、业务错误、图床 multipart、AI 协议与上传复用。组件测试覆盖手机 / 桌面响应布局和编辑导航。所有网络测试使用 MockClient，不调用真实小票机、图床或 AI。

预览图通过 Flutter 离屏渲染生成，不使用浏览器自动化。Android 预览 APK 使用开发测试签名；正式分发与稳定跨版本升级需单独配置持久的发布签名，签名文件不得提交 Git。
